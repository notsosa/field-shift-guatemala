## Cómo interpretar los resultados

Cada paquete declara producto, fechas, suelo, meteorología, parámetros, bibliografía y supuestos. Los datos originales se congelan para permitir comparaciones y reproducción. Los calendarios que llegan a 2026 se conservan sin evaluación hídrica completa; no se inventan lluvias para cerrarlos.

La simulación conserva el agua entre cultivos y compara déficit de evapotranspiración, días de limitación hídrica y riego hipotético. Las pruebas de software verifican contabilidad e integridad; la exactitud agronómica debe contrastarse con observaciones.

Las dos auditorías nuevas añaden exposición térmica y duración astronómica del día como indicadores descriptivos. La temperatura y el fotoperíodo no corrigen la fenología o el rendimiento en el motor hídrico. El ambiente cálido del candidato exige revisar adaptación antes de recomendar papa, brócoli o lechuga. No se certifica producción comercial con un déficit de agua bajo.

La sanidad, los residuos, la fertilidad, el drenaje real y el mercado requieren datos específicos. Las familias botánicas no generan premios automáticos, las corridas no representan ensayos de campo y los conteos de escenarios no son probabilidades de éxito.

## Entrega de las alternativas pendientes

Papa–cebolla y brócoli–lechuga reúnen **29,088 corridas**, **420 calendarios** y **20 pruebas superadas**. Cada carpeta incluye README, fuentes con alcance de lectura, código, configuración, entradas, resultados comprimidos, gráficas, controles e inventario. Sus cifras no se suman para crear un ranking entre productos con diferentes ciclos y demandas.
